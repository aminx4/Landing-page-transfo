# AGENTS.md

This file provides guidance to WARP (warp.dev) when working with code in this repository.

## Project Overview

Single-page executive landing page targeting banking IT leaders (CIOs, Heads of IT, Transformation Leaders) for Agile@Scale / IT transformation consulting services.

**Key constraints:**
- Peer-to-peer tone, never sales-y
- Trust-driven, executive-grade design
- Soft conversion only (calendar booking for 20-30 min discussion)
- No pricing, no aggressive CTAs

## Target Audience Profile

Banking CIOs and IT leaders who are:
- Busy, analytical, allergic to marketing hype
- Interested in outcomes, not frameworks
- Skeptical of typical consulting/coaching language

## Page Structure (5 Sections)

1. **Hero** — Value statement on scaling IT execution in banking, soft CTA, abstract illustration (no stock photos)
2. **Banking IT Challenges** — IT/Business misalignment, governance overhead, multi-team complexity, regulatory vs speed
3. **Value Proposition** — Agile@Scale models, delivery performance, strategy-to-execution alignment (outcome-focused, not certification-focused)
4. **Credibility** — European banking experience, large-scale transformations, CIO-level work (no fake logos)
5. **Soft CTA** — "Peer exchange" / "strategic discussion" with calendar booking integration

## Design Requirements

- **Colors:** Deep blue, white, light grey, subtle teal/gold accents
- **Style:** Premium consulting, minimalistic, enterprise-grade
- **Layout:** Single-page, strong visual hierarchy, generous whitespace
- **UX:** Mobile responsive, fast loading, smooth scrolling

## Content Rules

**DO:** Speak to leaders, be concise, focus on impact
**DON'T:** Oversell, use excessive buzzwords, mention pricing, sound like a coach selling SAFe

## Code Guidelines

- Keep sections modular with reusable components
- Comment major sections for maintainability
- Content should be easily editable (consider extracting to config/content files)
